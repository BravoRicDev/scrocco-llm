# Archivio documentale

Questa directory contiene documenti **superati**: piani, roadmap e specifiche
che descrivevano uno stato del codice poi cambiato. Sono tenuti per
tracciabilita (per sapere come si e' arrivati a un certo punto), NON vanno
aggiornati e non descrivono il codice attuale.

Se un documento qui contraddice il codice o il README di root, **il codice ha
ragione**: la documentazione attuale e' in `docs/` e in `README.md`.
